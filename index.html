GB Access

Play Game Boy games with your screen reader. This page tells VoiceOver and your braille display what is happening.

Load a game

Pick a Game Boy game file you own (it ends in .gb or .gbc). The file stays on your device. It is never uploaded.

No game file? Play the free demo game. It comes with GB Access.

Tobu Tobu Girl is by Tangram Games. Its code is MIT and its art and sound are CC BY 4.0. Demo game credits and license

Game Boy buttons

Double tap a button to press it once. To hold a button, double tap and hold.

Read memory (test)

This reads one spot in the game's memory and says its number. Later, this is how GB Access will know what is going on in a game.

Past messages

The newest is first. Good for reading again on braille.

    Keyboard keys

    • Arrow keys: the D-pad
    • X: A button
    • Z: B button
    • Enter: Start
    • Shift or Backspace: Select
    • P: pause or resume

    GB Access is free and open source under the AGPL-3.0 license. It uses the binjgb emulator by Ben Smith (MIT license). The only game included is the demo, Tobu Tobu Girl by Tangram Games (code MIT, art CC BY 4.0).
