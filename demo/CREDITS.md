# Demo game: Tobu Tobu Girl

GB Access comes with one free demo game, so you can try it right away.

- Game: Tobu Tobu Girl, an arcade jumping game for the Game Boy
- Made by: Tangram Games (source code by Simon Larsen)
- Get the game: https://tangramgames.itch.io/tobutobugirl
- Source code: https://github.com/SimonLarsen/tobutobugirl
- File here: demo/tobutobugirl.gb, the game's unchanged ROM (the same file as in the gbdev
  homebrew database: https://github.com/gbdev/database/tree/master/entries/tobutobugirl)

The game's code and art have their own licenses. They are not under GB Access's AGPL-3.0 license.
